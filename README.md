ARMAZENAMENTO E BACKUP
- O site salva automaticamente os cadastros no armazenamento local do navegador (LocalStorage).
- Não usa Firebase, banco de dados, servidor ou login.
- Os dados ficam apenas no navegador/aparelho em que foram cadastrados. Não sincronizam entre celulares ou computadores.
- Use Configurações > Backup completo (JSON) para guardar todos os clientes, corridas e configurações.
- Para recuperar os dados em outro aparelho, abra o site nele e use Restaurar backup.
- Exportar histórico CSV gera uma planilha apenas das corridas.
- Não limpe os dados do navegador sem antes fazer backup.

MAPAS
